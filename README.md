For you mom - Personal Music Streaming Platform
A personalized, Spotify-inspired web application built to celebrate and enjoy a curated collection of music. This project features a modern user interface, responsive design, and a full suite of playback controls.

🚀 Features
Curated Playlist: Pre-loaded with over 100 tracks.

Dynamic Music Player:

Playback Controls: Play, pause, next, previous, shuffle, and loop functionality.

Progress Tracking: Real-time progress bar with current time and total duration display.

Volume Control: Smooth volume slider with percentage indicator.

Search Functionality: Quickly find specific songs by title using the instant search bar.

Personalized Themes: Toggle between a sleek Dark Mode and a clean Light Mode.

Visualizer: A CSS-based equalizer animation that activates during playback.

Responsive Design: Fully optimized for both desktop and mobile viewing.

🛠️ Technology Stack
HTML5: Semantic structure for the web application.

CSS3: Custom styling with CSS variables for theming, CSS Grid for layout, and keyframe animations for the equalizer.

JavaScript (ES6+): Core logic for audio handling, playlist rendering, and UI interactions.

Cloudinary: Used for high-performance hosting and streaming of the audio files.

📝 Usage
Playing Music: Click on any song in the "Playlist" panel to start playback.

Searching: Type a song title into the search box at the top to filter the playlist instantly.

Theme Toggle: Click the moon/sun icon in the header to switch between Dark and Light modes.

Controls: Use the center console to shuffle your music or loop your favorite track.
